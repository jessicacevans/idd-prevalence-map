# IDD Prevalence Map — United States

An interactive choropleth map visualizing estimated **Intellectual and Developmental Disability (IDD) prevalence** per 1,000 population across all 50 U.S. states and Washington, D.C.

🗺️ **[View Live Map](https://jessicacevans.github.io/idd-prevalence-map/)**



## About

This map color-codes states into three prevalence tiers based on a national range of 10–13 per 1,000 population:

| Category | Range |
|---|---|
| 🔵 Lower | 10.0–10.9 per 1,000 |
| 🟠 Moderate | 11.0–11.9 per 1,000 |
| 🔴 Higher | 12.0–13.0 per 1,000 |

Hover over any state to see its abbreviation, exact prevalence estimate, and category.

Values are modeled estimates drawn from peer-reviewed literature and federal surveillance data — not official state statistics.

## How to Update

1. Edit the state prevalence values in the Python script
2. Run the script to regenerate `IDD_Prevalence_Map_fixed.html`
3. Rename the output to `index.html`
4. Upload and commit to this repository — GitHub Pages updates automatically
